# freespoof 🛡️

**تونل ضدسانسور دوطرفه با جعل منبع IP و مقاومت در برابر DPI**

`freespoof` یک تونل رمزنگاری‌شده‌ی نقطه‌به‌نقطه برای عبور از سانسور مبتنی بر DPI است،
روی مسیری که **هر دو سرِ آن را خودِ اپراتور کنترل می‌کند** و مجاز به ارسال بسته‌هایی با
منبعِ جعلی روی آن مسیر است. این پروژه هم‌خانواده‌ی ابزارهایی مثل WireGuard و
Xray/Reality و Trojan و Hysteria است، با این تفاوت که منبعِ بسته‌های خام IPv4 را نیز
جعل می‌کند تا الگوی ترافیک متنوع شود و در برابر محدودسازی بر پایه‌ی IP مبدأ مقاوم‌تر باشد.

> ⚠️ **کاربرد مجاز:** این ابزار برای مسیرهایی ساخته شده که شما هر دو انتهای آن را در
> اختیار دارید و قانوناً اجازه‌ی ارسال بسته با منبع جعلی روی آن مسیر را دارید
> (مثلاً دو سرور اجاره‌ای خودتان). هویت طرف مقابل **همیشه** به‌صورت رمزنگاری‌شده
> احراز می‌شود، نه با اعتماد به فیلد منبعِ جعلی.

---

## 🧭 مدل اعتماد

- هر بسته‌ی خروجیِ خام IPv4، یک **منبعِ جعلی** (`spoofed_ip`) دارد؛ اما **مقصد همیشه
  آدرس واقعی طرف مقابل** (`peer_real_ip`) است تا پاسخ‌ها به طرف واقعی برسند و مسیریابی
  کار کند.
- احراز هویت و کلیدهای نشست از طریق دست‌دادن **Noise_IK** (روی X25519) به دست می‌آید،
  به‌علاوه‌ی یک لایه‌ی اختیاریِ **PSK** به سبک WireGuard (`IKpsk2`).
- محرمانگیِ **پساکوانتومی**: دست‌دادن به‌صورت هیبرید با **ML-KEM** (FIPS-203) ترکیب می‌شود؛
  شکستن نشست مستلزم شکستن **هم** X25519 و **هم** ML-KEM است.
- ترافیک احراز‌نشده بی‌صدا دور ریخته می‌شود (fail-closed) تا وجود تونل برای پروب‌کننده لو نرود.

## 🔧 ساخت (Build)

نیازمند `rustc 1.75+`.

</div>

```bash
# بیلد معمولی
cargo build --release

# بیلد با فعال‌سازی AVX2/AVX-512 برای کریپتو/FEC/checksum
RUSTFLAGS="-C target-cpu=native" cargo build --release

# تولید جفت‌کلید استاتیک Noise برای هر طرف
./target/release/freespoof genkey
```

<div dir="rtl">

### باینری‌ها

- `freespoof` — باینری یکپارچه؛ نقش از روی `role` در کانفیگ یا `--role` انتخاب می‌شود.
- `freespoof-client` — نقش قفل‌شده روی client.
- `freespoof-server` — نقش قفل‌شده روی server.

## 🚀 اجرا

`freespoof` به دسترسی `CAP_NET_RAW` و `CAP_NET_ADMIN` نیاز دارد (یا اجرا با root):

</div>

```bash
sudo setcap cap_net_raw,cap_net_admin+ep ./target/release/freespoof
```

<div dir="rtl">

> **نکته‌ی مهم:** چون بسته‌های ورودی منبعِ جعلی دارند، باید `rp_filter` روی اینترفیس خاموش
> باشد (در مرحله‌ی استقرار به‌صورت خودکار تنظیم می‌شود):

</div>

```bash
sysctl -w net.ipv4.conf.all.rp_filter=0
```
